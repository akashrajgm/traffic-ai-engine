# Traffic Vision AI Engine 🚦

Standalone inference server built to deploy high-density deep-learning traffic analytics.

## 📺 Project Demo
<video src="https://github.com/akashrajgm/traffic-ai-engine/releases/download/v1.0.0/traffic_ai_demo.mp4" width="100%" controls></video>

## 🚀 Overview
This engine utilizes YOLOv8m and ByteTrack logic, specifically calibrated for high-resolution traffic analysis on Apple Silicon. By implementing custom Region of Interest (ROI) logic, the system ensures stable ID persistence and accurate vehicle counting.
